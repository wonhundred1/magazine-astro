**Hub stay: Busan** · **Car:** no · **Return:** Busan bed · **Angle:** festival peak vs quiet canal

Yeojwacheon is the walkable canal spine of **Jinhae (Changwon)**. VisitKorea frames **Jinhae Gunhangje** as the spring cherry-and-navy festival; the **2026** window class is listed **2026-03-27 ~ 2026-04-05**, with Yeojwacheon among the classic photo belts. The rest of the year the same path is a slower café street — still worth the coach if you like water and low hills, not if you only want peak blossoms.

## Who it is for
- Travelers already sleeping in **Busan** who want a half-to-full day without a car
- People deciding **Gunhangje week** vs an ordinary Saturday
- Walkers OK with festival crush or, off-peak, ordinary shop hours that change often

## Place facts (official paraphrase — checked 2026-11-27)

| Spot / season | Anchors |
|---|---|
| **Yeojwacheon** | Canal walk + bridges + café belt in Jinhae-gu · free outdoor path |
| **Gunhangje** | VisitKorea: navy memorial + cherry themes · **2026-03-27 ~ 2026-04-05** class · Jungwon / Bukwon rotaries · military band / open-base style programs on festival days — **reconfirm year sheet** |
| **Other cherry pins** | VisitKorea also names Naesumyeon eco park, Gyeonghwa station, Jinhae Tower / monorail class — optional second stop only if daylight remains |
| **Quiet months** | Same canal; fewer pop-ups; permanent cafés matter more than temporary stalls |

## Transit table (patterns — boards win)

| Leg | Mode | Notes |
|---|---|---|
| Hotel → **Sasang / Seobu** | Metro Line 2 | Terminal belt for many west-coast / Changwon legs |
| Seobu → **Jinhae** | Intercity coach | Some corridors are **few trips per day** — screenshot the morning board; do not invent a clock |
| Terminal → Yeojwacheon | Local bus / short taxi / walk | Pin the canal first; festival alighting queues grow fast |
| Optional monorail / tower | Local hop | Only if legs and daylight allow after the canal |
| Return → Busan | Same coach | Festival evenings fill early — buy return mindset before lunch |

## Hourly outline

| Time | Gunhangje peak day | Quiet-season day |
|---|---|---|
| Early morning | Seobu out; layers for wind | Same |
| Late morning | Canal one-way; accept crowds | Slow canal + photo bridges |
| Midday | Simple meal off the densest bridge | Café sit-down OK |
| Early afternoon | One extra pin (tower / rotary) **or** start return | Optional second walk belt |
| Mid–late afternoon | Protect coach buffer | Soft return to Busan plans |

## Festival vs quiet season

| Item | Gunhangje (~late Mar–early Apr class) | Other months |
|---|---|---|
| Crowds | Heavy on bridges and rotaries | Light–moderate |
| Photos | Iconic blossoms | Everyday canal stroll |
| Shops | Pop-ups + longer lines | Permanent cafés matter more |
| Strategy | Earlier start, shorter loop | Coffee + slow walk |

## Food method (no invented shops)

| Zone | How to choose |
|---|---|
| Canal bridges | Filter **Open now**; save road address; skip unnamed stalls in sales lists |
| Near terminal | Faster bowls if the festival line kills lunch |
| Busan dinner | Often calmer than forcing a late Jinhae queue |

Names along the canal churn. Seasonal pop-ups are not place-registration inventory until verified.

## Hub stay honesty
- Sleep in **Busan** for this day-trip framing.
- Do not stack Jinhae + Tongyeong + sunset on the same winter clock.

## Manners
- Bridges are shared with strollers and tripods — keep a lane.
- Navy / open-base programs: follow steward directions; no drone freelancing over restricted zones.
- Pack out cups; canal water is not a trash chute.
