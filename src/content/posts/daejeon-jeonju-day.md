Jeonju from **Daejeon** is the clean Jeolla day: ~**1h30** express, Hanok village walk, reverse before the late bus. This is **not** the long Busan day — see [Jeonju from Busan](/posts/jeonju-hanok-long-day/) if that is your hotel.

## Who it is for
- Guests already sleeping in Daejeon (business / rail transfer / multi-day gate)
- Walkers who want village lanes without inventing shop rankings
- People who will book **return seats** before lunch on Saturdays

## Place facts (checked 2026-11-26)

| Spot | Anchors |
|---|---|
| **Jeonju Hanok Village** | Official **hanok.jeonju.go.kr** maps · Gyeonggijeon / Omokdae / alley spine · residential + commercial mix |
| **Jeonju Express Bus Terminal** | Drop for Daejeon expresses · taxi/bus to village (~10–20 min class) |
| **Gyeonggijeon** | Ticketed historic house when open — hours on site board |
| **Nambu market / film street edges** | Daylight food-search zones |

## Transit table (patterns — KOBUS wins)

| Leg | Mode | Notes |
|---|---|---|
| Daejeon hotel to Complex Terminal | Metro / taxi | Buffer for first buses |
| Daejeon Complex to Jeonju Express Terminal | Express deluxe class | Public tables: first ~**06:30**, last ~**22:30**, ~**1h30**, fare band often **~₩12,200** (night higher) — **reconfirm** |
| Terminal to Hanok village | Taxi / city bus | Save village pin; weekend traffic |
| Village to terminal | Reverse | Leave 60+ min before your booked return |
| Optional Yuseong origin | Intercity | Only if ticket says Yuseong — different bay |

## Hourly sketch

| Time | Move |
|---|---|
| 07:00–08:00 | Depart Daejeon |
| 09:00–12:00 | Gyeonggijeon + main lanes |
| 12:00–14:00 | Food-search method (bibimbap / hangover stew clusters) |
| 14:00–16:00 | Omokdae overlook / side alleys / café sit |
| 17:00– | Terminal; evening express to Daejeon |

## Stops (walk order)
1. Daejeon Complex Terminal boarding  
2. Jeonju Express Terminal arrival  
3. Gyeonggijeon / main Hanok lanes  
4. Omokdae overlook or side alleys  
5. Return terminal with buffer

| Area | Method |
|---|---|

## Overnight honesty
- Sleep **Daejeon** for this recipe.
- Jeonju overnight is great for a multi-day Hanok stay — different product.
- Do not add Imsil cheese the same afternoon unless you already know the last coach.

## Manners
- Quiet residential edges after dusk.
- No blocking gates for photos; drones often restricted.
- **1330**; village desks on official maps.
