**Hub stay: Suncheon** (Gwangju OK) · **Car:** no · **Return:** hub bed · **Not:** rushed Busan same-day

Boseong’s **Daehan Dawon** terraces are a classic Namdo photo day — and a classic place people under-budget the coach. Sleep in **Suncheon** (lodging-rich, already on the bay/garden circuit) or **Gwangju**, not a fantasy Busan round trip.

## Who it is for
- Travelers who want one deep **tea landscape** walk with honest winter closing time
- People already near Suncheon Bay / Yeosu who can spare a coach day
- Visitors fine paying a small plantation fee instead of hopping fences

## Transit table (patterns — boards win)

| Leg | Mode | Notes |
|---|---|---|
| **Suncheon** stay → Suncheon Terminal / Station | Walk / taxi | Preferred lodging-rich base for this piece |
| Suncheon → Boseong | Intercity / rural coach | Multi-stop possible; morning-out evening-back |
| **Gwangju (U-Square)** → Boseong | Intercity | Public pattern tables often show daytime coaches (first ~**06:40** class toward Boseong belt) — **reconfirm** |
| Boseong-eup → Daehan Dawon | Local bus / taxi | Last mile is the usual failure point — save the pin |
| Return → hub | Reverse coach | Winter **17:00** gate means you leave the field with light still useful for the bus stop |

## Hourly outline (winter from Suncheon)

| Time | Plan |
|---|---|
| Morning | Coach to Boseong; taxi/bus to gate |
| Late morning | Terrace loops + cedar path (soft light) |
| Midday | Simple lunch in Boseong-eup or gate snacks if open |
| Early afternoon | Second short loop / shop only if queues are short |
| Mid afternoon | Exit before **17:00** stress; coach back to Suncheon |

## Hub stay honesty
- **Suncheon** pairs cleanly with [Suncheon Bay Garden](/posts/suncheon-bay-garden/) on another day.
- **Gwangju** works if you already sleep there for Damyang/Gokseong spokes.
- Boseong overnight only with a real booking.

## Manners
- Stay on marked paths; terraces are working agriculture.
- Drones and loud speakers annoy staff and birds.
- **1330** · plantation **061-852-4540**.
