**Hub stay: Mokpo** · **Car:** no · **Airport note:** Muan (MWX) → ground transfer · **Not:** Busan same-day

Mokpo is a **lodging-rich port city**. Stay here and move nearby. Do not treat this as a rushed round trip from Busan.

## Who it is for
- Travelers entering west Jeolla by KTX/SRT/coach  
- People building Jindo / Haenam / island legs from a stable hotel base  
- Gyopo / Korean-map users OK with city buses  

## Arrival table (patterns — reconfirm same day)

| Leg | Mode | Notes |
|---|---|---|
| Seoul area → Mokpo Station | KTX/SRT | Public course examples often ~2–2.5 h from Yongsan/Suseo — **times change** |
| Seoul area → Mokpo Bus Terminal | Express coach | Multi-hour; use terminal boards |
| MWX → Mokpo | Airport bus/taxi | Build buffer |
| Station/terminal → hotel | Taxi / city bus | Save hotel pin the night before |
| Busan → Mokpo | Long coach/rail | **Relocation day**, not a sightseeing day |

1. In-city: Yudalsan, modern history street, **marine cable–Gohado** (deep piece), Gatbawi evening.  
2. Day radius: Jindo, Haenam Usuyeong — return to **Mokpo bed**.  
3. Ferries: only with same-day timetable proof.
