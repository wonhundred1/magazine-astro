**Hub stay: Andong** · **Car:** no · **Return:** Andong bed · **Mode:** full culture day

Hahoe is the reason many travelers pick an [Andong hub stay](/posts/andong-hub-stay/). Give it a **whole day**. Winter light is short; the gate closes earlier than summer blogs remember.

## Who it is for
- First-time UNESCO village walkers who accept 2–4 hours on foot inside the village
- Travelers who will not invent a same-day Busan return after the last shuttle
- People okay paying a modest heritage fee instead of hunting “secret free entries”

## Place facts (public society / VisitKorea paraphrase — 2026-11-26)

| Item | Anchor |
|---|---|
| **Address class** | Pungsan / Pungcheon-myeon belt — **Jeonseo-ro 186** class pin |
| **Hours** | Summer (Apr–Sep) often **09:00–18:00** (entry cut ~17:30) · **Winter (Oct–Mar) 09:00–17:00** (entry cut ~**16:30**) · year-round open day pattern |
| **Fees (individual)** | Adult **₩5,000** · youth/uniform **₩2,500** · child **₩1,500** class · group discounts on society boards · local resident discounts exist — **carry ID** |
| **Free cases (examples on society lists)** | Age 65+ domestic, some disability companions, a few national holiday free days — read the live board |
| **Parking / shuttle** | Society guidance commonly lists **free public parking** and **free shuttle** segments — still ask the ticket booth for today’s loop |
| **Time on site** | Society FAQ class: **2–4 h** village walk; **Buyongdae** or Byeongsan seowon need **extra** time |
| **Desks** | Ticket **054-840-3801** · guide desk **054-840-3803** class |

## Transit table (from Andong stay)

| Leg | Mode | Notes |
|---|---|---|
| Hotel → Andong Station / Terminal cluster | Walk / taxi / city bus | Confirm which stop the Hahoe tourist bus uses **this season** |
| Andong → Hahoe entrance | Tourist bus / local bus / taxi | Morning outbound; save return clock before you enter |
| Inside village | Walk | Narrow lanes; strollers struggle on some paths |
| Optional Buyongdae | Taxi / local link + climb | Viewpoint of the S-curve — budget a separate block |
| Return → Andong | Reverse bus / taxi | Do not cut it fine against winter dark |

## Hub stay honesty
- Base is **Andong city**, not a countryside guesthouse you invent.
- Mask dance calendars and line-fire shows are **seasonal** — only publish a show time when the live calendar says so.
- Pair evening [Woryeonggyo](/posts/andong-hub-stay/) on another night, not after a drained Hahoe day unless energy is high.

## Manners
